# 轨道插值器（Animation Track Interpolator）

Godot 4 编辑器插件，以**停靠面板**形式存在：修改指定的 `AnimationPlayer` 中指定动画的**数值类轨道**，
把它的关键帧按指定的方式**从起始值过渡到终点值**。

## 启用

插件已在 `project.godot` 的 `[editor_plugins]` 中注册，打开工程即生效；
也可以在 `项目 → 项目设置 → 插件` 里手动勾选 `轨道插值器 Animation Track Interpolator`。

## 使用

打开面板：编辑器右侧停靠栏中的「轨道插值器」（槽位：右上）。

1. **AnimationPlayer** —— 自动列出当前编辑场景（含实例化子场景内部）的所有 `AnimationPlayer`，
   也可用编辑器里选中节点的方式自动跟随；`刷新` 重新扫描。
2. **动画** —— 该播放器里的全部动画；带命名库的动画显示为 `库名/动画名`。
3. **轨道** —— 选中动画的轨道列表，显示为 `索引 · 类型 · 路径`。
   只有数值类轨道可选（`值` / `位置 3D` / `旋转 3D` / `缩放 3D`），且关键帧需 ≥ 2 个。
4. **插值方式** —— 关键帧从起始值过渡到终点值所采用的曲线：

   | 方式 | 权重 w(t) |
   | --- | --- |
   | 线性（匀速） | `t` |
   | 平滑（缓入缓出） | `t²(3-2t)` |
   | 缓入（加速） | `t²` |
   | 缓出（减速） | `1-(1-t)²` |
   | 正弦过渡 | `0.5-0.5·cos(πt)` |
   | 阶跃 | `t < 1` 时保持起始值 |

5. **起始值 / 终点值** —— 每个通道 `X / Y / Z / W` 前都有勾选框：
   - **勾选**：该通道的输入框可编辑，其数值会参与插值；
   - **未勾选**：输入框变灰不可修改，该通道**逐帧保持原关键帧数值**；
   - 起始值、终点值两侧都没勾选的通道完全不被修改；一个通道都没勾选时不会执行任何修改。
   默认全部勾选（`旋转 3D` 轨道除外，见下方说明）。数值默认自动读取该轨道的首帧/尾帧值（切换轨道时自动填充，勾选状态保留）；
   `位置 3D / 缩放 3D` 显示 X/Y/Z，值轨道按类型显示 1~4 个框，通道数不足时多余的框自动隐藏；
   `旋转 3D` 显示欧拉角 X/Y/Z（度）。
   `从首尾关键帧重新读取` 可随时还原数值。
6. **只保留首尾两个关键帧** —— 勾选后删除中间帧，只留首尾两帧，由 Godot 自身在这两个值之间过渡。
7. **应用到选中轨道 / 应用到全部数值轨道** —— 前者使用界面上的起始值/终点值；
   后者对每条数值轨道分别用**各自**的首尾关键帧值，两者的勾选通道规则一致。

时间点默认保持不变，只重写每一帧的值；旋转轨道（四元数）使用 `slerp` 走最短路径并归一化。

> **关于旋转轨道**：`旋转 3D` 轨道存的是四元数。为了好读好改，界面把它**按欧拉角（单位：度）显示**：
>
> - 只显示 `X / Y / Z` 三个框（后缀为 `°`，步长 0.1，方向键步长 1°），W 分量不再出现；
> - 你输入的欧拉角会在应用前换算成四元数，帧与帧之间依旧用 `slerp` 走最短路径；
> - 只读不改不会动到动画：把显示的欧拉角原样换算回四元数得到的仍是同一个旋转（已用 200 组随机旋转验证）；
> - 由于四元数的四个分量共享同一个归一化约束，**无法只改其中一两个分量**，
>   因此选中旋转轨道时三个勾选框会被锁定为全勾选（不可操作），勾选某个轴**不代表**"只绕该轴旋转"。
>   需要"只动某个轴"的轴锁定（欧拉空间）可以另行提出；
> - 欧拉角是 YXZ 序的规范分解：当 `Y` 接近 ±90°（万向锁）时，Godot 会把 `X`/`Z` 合并成等价的一组角度，
>   显示数值可能与你原来的写法不同，但表示的旋转完全一致。

## 说明

- 修改走 `EditorUndoRedoManager`，可用 `Ctrl+Z` / `Ctrl+Y` 撤销重做；修改后会标记场景为未保存。
- 面板底部会显示当前轨道信息与「动画来源」：外部 `.tres` 资源会显示资源路径，
  内嵌资源（例如 glTF 导入场景内的动画）显示为「场景内嵌资源」，需随场景一起保存。

## 文件

```
addons/animation_track_interpolator/
├─ plugin.cfg                    插件描述
├─ plugin.gd                     插件入口，注册停靠面板
├─ track_interpolator_dock.tscn  面板界面（全部控件都在场景内）
├─ track_interpolator_dock.gd    面板逻辑
└─ track_interpolator_core.gd    纯逻辑：插值曲线与轨道关键帧重写（可单独测试）
```
